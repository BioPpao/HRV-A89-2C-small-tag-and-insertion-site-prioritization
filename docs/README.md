## Writing rules

A decision-changing report should state:

1. input files and versions;
2. method/thresholds;
3. evidence classes;
4. numerical result tables or links to machine-readable data;
5. interpretation boundaries;
6. what changed from the previous version;
7. the next decision-changing analysis.

Do not present model-derived conclusions as direct experimental evidence.
