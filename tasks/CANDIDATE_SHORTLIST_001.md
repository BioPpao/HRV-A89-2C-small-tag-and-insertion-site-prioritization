# CANDIDATE_SHORTLIST_001

## Purpose

Define the evidence-based candidate junction shortlist before any Tag × Site perturbation modeling.

This task is a decision gate, not a final validation step.

## Scope

Allowed:
- Integrate functional exclusion, structural screening, HRV-A conservation, indel context, and literature evidence.
- Classify candidate junctions.
- Define entry criteria for future Tag × Site modeling.

Not allowed:
- Start HA/MAP8/G196 modeling.
- Declare any site safe or validated.
- Design experimental constructs.

## Evidence hierarchy

1. Functional constraints
2. Structural compatibility (monomer + hexamer)
3. Evolutionary context
4. Literature rescue evidence
5. Future tag perturbation modeling

## Required outputs

- docs/CANDIDATE_SHORTLIST_001_DECISION.md
- Updated project state files
- Explicit candidate tiers
- Preserved evidence conflicts

## Candidate language

Use:
- primary review candidate
- secondary candidate
- literature rescue control
- excluded

Do not use:
- safe site
- validated insertion site
- proven tolerant site

## Scientific principle

Evolutionary variability supports local flexibility hypotheses but does not demonstrate compatibility with artificial peptide insertion.
